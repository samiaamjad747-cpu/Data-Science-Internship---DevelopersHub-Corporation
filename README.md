#  Task 4: Insurance Claim Amount Prediction 

 
##  Objective
Developed a machine learning model to predict the insurance claim amount based on customer and policy data.

##  Dataset
Insurance Claim Dataset (e.g., Kaggle / CSV dataset)

##  Key Activities:
Performed data cleaning and preprocessing:
Handled missing values using mean/median
Removed or treated outliers
Conducted Exploratory Data Analysis (EDA):

Impact of age, BMI, and smoking status
Relationship between features and claim amount

One-Hot Encoding for features like region and gender

Linear Regression
Decision Tree Regressor
Evaluated model performance using:
Mean Absolute Error (MAE)
Mean Squared Error (MSE)
R² Score
